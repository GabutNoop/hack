# Workspace ops

Gunakan tool file/terminal Hermes, jangan mengarang isi file.

1. Cek workspace aktif dulu.
2. List atau baca file yang relevan sebelum mengubah.
3. Edit seminimal mungkin, lalu verifikasi (baca ulang / jalankan tes).
4. Jangan hapus data di luar workspace tanpa konfirmasi eksplisit.
